# PicLab Studio — 模板设计规范 (Template Design Guide)

> 本文件是 L1 内置模板与 L2 场景的**强制性设计规范**。所有模板必须在写节点前先写 brief（含色彩 token / 字体 token / 网格 / 签名动作），并逐条通过检查清单。

---

## 1. 字体角色与气质

选字体的逻辑：**先定气质，再选字**。每张模板只允许 **≤ 2 个主导字族**（一个 display、一个辅助），靠字重/字号/颜色做层级。

| Role | 字体 | 气质 | 场景 | 警示 |
|---|---|---|---|---|
| `display` | 得意黑 | 刚硬、现代、力量 | 中文英雄标题 | 不用在正文；不用在柔情场景 |
| `script` | 马善政 | 笔墨、情绪、东方 | 单个字/印章/情感叠字 | 不用长句；每张 ≤ 1 处 |
| `serifQuote` | 霞鹜文楷 | 文气、安静、诗意 | 诗句/引用 | 不用于标题 |
| `fang` | 站酷小薇 | 雅致、纤细 | 展讯/说明/副标 | 不用于标题；≥ 18px |
| `latinDisplay` | Bebas/Anton | 建筑感、压缩、冲击 | EN 大标题 | 需 condense 0.8-0.9 增强压缩感 |
| `latinSerif` | Playfair | 优雅、古典 | EN 点缀/翻译 | 不用于长正文 |
| `meta` | Outfit | 中性、工具 | VOL/日期/联系方式 | 永远 Regular/Medium，不用于标题 |
| `mono` | Space Grotesk | 代码、编号 | SKU/编号 | 仅点缀 |

**组合公式（按气质选）**：
- 力量型：`latinDisplay(EN 大) + display(中文叠) + script(单字点缀)`
- 文雅型：`serifQuote(诗句) + fang(展讯) + latinSerif(EN 点缀)`
- 促销型：`latinDisplay(数字) + display(卖点) + meta(CTA)`

**禁止**：
- 两种字体气质相似且同字号（无层级）
- 全模板只用一个字体家族
- `script` 写长句子
- 中文场景用 UI sans（苹方/雅黑）做标题

## 2. 文字描边 / 晕轮（何时用，何时不用）

**核心原则：描边是"可读性工具"和"装饰手法"，不是默认设置。**

| 场景 | 处理 |
|---|---|
| 文字叠在复杂/多纹理照片上 | **用 halo**：同色系深色（如 `rgba(8,18,12,0.5)`）描边 3-6px。目的是让笔画与照片分离 |
| 文字叠在干净天空/纯色/同色区 | **不用 halo**。直接纯色。照片同色调区其实可读 |
| 纯色面板 / 色块上的文字 | **永不描边**。用色块本身保证对比 |
| 装饰性描边字（潮流/复古风） | **只在特定模板用**：描边字 + 实心字并置，制造线面/虚实对比；字号与实心字接近 |
| 正文 / body copy | **永不描边**（strokeWidth: 0） |

**参数**：
- 可读性 halo：`rgba(0,0,0,0.35–0.55)` 或 `rgba(255,255,255,0.55)`，宽度 3-4px，**方向永远向外**
- 装饰描边：与填充色对比鲜明，宽度 = 字号的 4-7%
- 判断标准：描边后文字轮廓仍清晰，不能糊成一团

**现有模板中 must-fix**：
- `socialQuoteCover` 顶部 `NIGHT NOTE` 在纯墨色字场上用了金色 bold —— 不需要描边（纯色背景）
- 叠在照片上的标题缺 halo → 读不清
- 全模板滥用描边 → 显得业余

## 3. 配色（60-30-10 + 低饱和基底）

每个模板必须定义 **色彩 token**（`field / panel / ink / mute / accent`），并在 brief 中标注使用比例。

- **60% 主色**：`field` 或照片 —— 奠定氛围。大面积区域**降低饱和度**（高级感来源）
- **30% 辅助色**：`panel` —— 信息承载区/排版板
- **10% 强调色**：`accent` —— **只出现 1-2 处**，且必须有明确工作（CTA、日期、签名线）。绝不平均用力

**规则**：
- 同色系/莫兰迪（统一饱和度明度、微调色相）最稳
- 冷暖对比（深蓝+米色、墨绿+柠檬）制造高级层次
- 互补色（红绿/蓝橙）**只小面积用**（10%），且降低其中一个饱和度
- **禁止**：大面积高饱和叠加、把强调色当背景用、5+ 种颜色堆砌
- 文字对比度：正文 ≥ 4.5:1，标题 ≥ 3:1（可借 panel 保证）

**配图固有色调（必读）**：
- **从照片提取色板（median-cut / 量化）**：分析配图各区域的平均色 + 明度（luminance），得到 2-3 个主色 + 各区域亮度。据此定：
  - `field` = 照片本身（占 60%）
  - `panel` = 照片主色的**深色变体**（如青绿图 → 深墨绿 #14241C），文字与照片在同一调性
  - `ink` = 骨白/米白（暖调白比纯白更耐看，如 #FFF8EC）
  - `accent` = 与照片主色的**冷暖互补**，且**低饱和**（莫兰迪：灰调+柔和，比纯高饱和更高级）
- 配图分区明度决定文字处理：
  - 亮区（天空 luminance>160）→ 深色文字 / 或浅色字 + 深 halo
  - 暗区（山体 luminance<120）→ 浅色文字
  - 中灰区 → 自由，但需 halo 保证可读
- **文字对比度必须量化（WCAG）**，不要凭感觉：
  - 对比度 = (L_亮 + 0.05) / (L_暗 + 0.05)，L = 0.299R + 0.587G + 0.114B
  - 正文 ≥ 4.5:1，大字标题 ≥ 3:1
  - 陷阱：沙金 #D9A441（L≈169）叠在亮天空（L≈160）上对比度仅 **1.05**，几乎隐形！亮背景上的 accent 文字**必须配深色 halo**（`rgba(8,18,12,0.6-0.7)` 3-4px）才能立住
  - 骨白 #FFF8EC 叠在亮天空上也只有 1.3 左右 → 同样需要 halo 或渐变晕
- **竖向渐变晕罩（标题区专用的高级对比方案）**：
  - 平铺色罩（rgba 整体压暗）会压死天空；**竖向渐变** `linear-gradient(180deg, rgba(8,18,12,0.46), …渐隐至透明)` 让顶部深、向下通透
  - 渐变晕高度要**盖住标题区**（如标题 y204-680 → 晕 0-760），标题背景亮度可压暗 25-30%
  - 渐变晕承担对比度职责后，标题 halo 可**减细**（5px → 4px），楷书笔画更清爽
- 反例：
  - 青绿山野图配柠檬黄 accent（靠色、跳不出）
  - 珊瑚橙（#E85D4C）是"展讯"的签名色，**每个模板要有自己的 accent**，不与其它模板雷同
- **克制配色**：`#333` 而非纯黑（减视觉疲劳）；白底用三级灰度（主 `#111` / 次 `#666` / 装饰 `#CCC`）

**必须修正的现有问题**：
- 多张模板共享"骨白+深绿+珊瑚"配色 → 无差异化（每张模板必须自定 accent 与 panel）

## 4. 字号与层级

- 主标题 ≥ 副标题的 **2-3 倍**（如 120px / 40px），正文与主标可拉开 **3-5 倍**字号跨度
- 一张画布阅读路径上 ≤ 3 层字号（不含装饰字）
- 行距（来自中文排印规范）：
  - 中文正文：字号 × 1.6-1.8（方块字需要比英文更大的行距）
  - 标题：字号 × 1.2-1.3（字少，紧凑更显有力）；多行标题 1.3-1.4
  - 诗句：字号 × 1.5 左右
- **字距（Tracking）——最容易出高级感也最容易翻车的细节**：
  - 大字标题（48px+）：**负字距 -2% ~ -5%**，让大字更紧凑自信（默认字距在超大字号下显得过松）
  - 全大写英文眉标/标签：**正字距 +5% ~ +10%**（等宽高度下字距太紧会粘连；拉开才有编辑感）
  - 小字/注释：+2% ~ +5% 提升可读性
  - 中文默认字距恒定（letter-spacing:0），仅极大字号可收紧
  - 实现：模板系统无 letter-spacing 参数 → 用**空格**模拟正字距（如 `O P E N   F I E L D`），用 `condenseText`（scaleX 0.85-0.9）模拟负字距
- 间距取 **8px 倍数**（16/24/32/40/48/56/64/80…），所有坐标/字号/间距落到同一模数上
- 缩进/对齐：同一轴线（左轴 / 右轴 / 中轴），信息贴轴走
- **权重对比**：粗字重与细字重并置（Black + Light）比加大字号更有编辑感；同一字体家族内变字重不算加字体

**层级公式（自上而下）**：
```
meta 信息 (20-24px)   →  eyebrow（正字距，全大写）
display 标题 (96-160px) →  hero（负字距 / 竖排拉开）
fang/serif 副标 (24-32px) → support
caption/正文 (14-22px) →  detail
```

**竖排中文标题（东方美学高级感）**：
- 竖排大字 + 字距拉开（如"立夏"竖排两字，字距 = 列距，制造向下延展的节奏）
- 顶部配小号日期/刊头（细体、字距加宽），形成"上信息 → 中竖排大字 → 下留白"的节奏
- 竖排用 `writingMode: 'vertical'`，字距用 `lineHeight`（竖排时控制字符纵向间距）
- 搭配：竖排中文主标 + 横排细体英文对位，中英横竖对比即设计感
- **竖排不能用斜体字体**：Smiley Sans Oblique（得意黑）是斜体，竖排时字形倾斜发虚，**必须用楷书/宋体/非斜体**（霞鹜文楷 FONT_SONG 是最稳的竖排书法字体）
- 竖排时 transform.x 是列中心 → 字块左缘贴左轴需 `x = M + fontSize/2`

## 5. 网格、构图与留白

- **建立网格**：1080 宽 → 左轴 64 / 右轴 W-64；文字区块贴轴
- **三分法**：焦点元素（标题）放在画面 1/3 偏上偏左
- **黄金分割 1:1.618**：主体视觉占 5 份、文字区占 3 份；或留白:内容 = 1:1.618
- **极端留白 = 高级感**：艺术展海报常用 2:8（主体 20% / 留白 80%）。留白不是空白，是"最贵的空气"——周围越干净，焦点越清晰
- **不对称留白制造"反作用力"**：顶部大留白+底部小留白引导从上往下读；左重右轻让视线滑向右侧
- **聚焦留白**：重点元素周围挤出更大负空间，其余区域收紧；均匀分布留白会太平
- **排版板内的垂直节奏（编辑式信息块）**：
  - 信息成组：**主信息块（如诗句）紧凑 + 分隔线贴近下缘 + 底部脚注贴板底**，形成"紧凑块 → 中段呼吸 → 贴底"三段式
  - 反例：分隔线悬在诗句与脚注正中 → 上下各留一半空，节奏"塌"
  - 板顶发丝线（accent 1-1.5px）+ 板上缘间距 24px；诗句距板顶约 100px；板内线与诗句底距 30-60px；脚注贴板底留白 80-140px
- **安全区**：微信公众号头条内容在中央 60% 宽度内；社交图关键文字避开四角
- **图像裁切**：`makeImageInRect` cover crop 默认居中；想改变构图 → 用 `makeImageInRect` 指定裁切框（把焦点偏移到三分法交叉点）
- **缩小到 20% 检查**：焦点是否清晰、版面是否拥挤；模糊就做减法

**视觉层级三支柱**（Rishfield）：
- **Scale**：主体必须最大，胆小的大小差异 = 平淡
- **Contrast**：单一亮色在静背景上永远赢第一眼
- **Weight + Spacing**：粗细对比 + 留白隔离 = 焦点自动浮现

**签名动作**（每个模板唯一）：
- 一个记忆点即可：竖排大字 / 印章 / 巨型叠字 / 索引带 / 山脊线 / 描边对撞…
- 其余元素保持安静

## 6. 编辑/杂志式版式（editorial）

海报是"用比例说服人的论证"，网格是骨架。参考瑞士国际主义排版（Müller-Brockmann / Emil Ruder）：

- **三层信息**：primary（主标题，唯一焦点）→ secondary（日期/地点/副标）→ tertiary（脚注/版权）
- **左对齐 + 右侧参差**（flush-left, ragged-right）：最稳的编辑式文本设置
- **非对称布局**：拒绝居中对称，信息偏置 + 留白平衡
- **文字与图像永不接触**：给文字区留独立板块，或跨接缝用索引带明确分隔
- **网格是诊断工具**：任何元素"飘在网格之外"都意味着层级是偶然而非设计
- 有意的破格（如 1-2 个元素偏移 0.5 格）制造微妙的张力，但整版仍要有根

## 7. 检查清单（每个模板发布前逐条过）

- [ ] Brief 写了色彩/字体/网格/签名 token
- [ ] 照片或纹理在做真正的构图工作（不是色块假装设计）
- [ ] 字号层级满足 主:副 ≥ 2:1，阅读路径 ≤ 3 层
- [ ] 描边只在"复杂照片上的可读性"或"装饰对撞"场景出现
- [ ] 强调色 ≤ 2 处，有明确工作
- [ ] 文字与主轴线对齐，间距 8px 倍数
- [ ] 留白 ≥ 20%，无信息堆砌
- [ ] 缩到拇指尺寸仍可读（缩略图测试）
- [ ] 与其它内置模板构图不雷同（不是改个色）

## 8. 硬逻辑自动检查（审丑引擎）

无法定义"美"，但可计算"一定不美"。以下规则已固化为代码
（`src/studio/templates/designAudit.ts`），跑 `npm run smoke` 自动执行，
也可在浏览器控制台对任意模板手动调用：

```ts
const { getBuiltinTemplate } = await import('/src/studio/templates/builtins.ts');
const { auditDocument, summarizeIssues } = await import('/src/studio/templates/designAudit.ts');
const doc = await getBuiltinTemplate('builtin-poster-field').build({ assets: new AssetStore() });
summarizeIssues(auditDocument(doc)); // { errors, warnings }
```

**error（确定性丑，必须为 0）**：

| 规则 id | 判定 | 依据 |
|---|---|---|
| `vertical-oblique-font` | `writingMode==='vertical'` 且字体名含 Oblique/Smiley Sans | 得意黑竖排字形发虚 |
| `serif-condensed` | 衬线字族被 `scaleX<0.95` 压扁 | Playfair 等优雅衬线禁 condense |
| `text-overflow` | 文本世界包围盒超出画布 >8px | 裁切必丑 |
| `tiny-cjk-text` | 中文文本 `fontSize<20` | 拇指尺寸不可读 |
| `accent-on-photo-no-halo` | 亮色文字（lum≥0.45）叠照片且无 halo/色罩 | WCAG 对比度不足 |

**warn（统计丑，需人复核）**：

| 规则 id | 判定 |
|---|---|
| `hierarchy-gap` | 最大/次大字号 < 2（胆小的大小差异） |
| `too-many-size-steps` | 一屏 >4 档字号（阅读路径混乱） |
| `halo-on-solid-backdrop` | 纯色背景上的文字用了描边 |
| `vertical-x-unanchored` | 竖排 x 非常规值（疑似忘了 `轴+fontSize/2`） |

**局限**：引擎不感知照片像素与设计意图。同一帧 5 档字号可能是
有意的编辑式节奏（如"旷野"176/40/30/26/24），warn 不等于错。
