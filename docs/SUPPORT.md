# Support

Where to ask for help with PicLab Studio.

## Try first

1. Open the [live demo](https://marsresearcher.github.io/piclab/) (no account).
2. Skim [`getting-started.md`](getting-started.md) and [`PRODUCT.md`](PRODUCT.md) (beachhead & non-goals).

## Channels

| Need | Where |
| --- | --- |
| Usage questions, “how do I…”, early ideas | [GitHub Discussions](https://github.com/MarsResearcher/piclab/discussions) |
| Clear bug with repro steps | [Bug report](https://github.com/MarsResearcher/piclab/issues/new?template=bug_report.yml) |
| Feature that fits offline-first Studio | [Feature request](https://github.com/MarsResearcher/piclab/issues/new?template=feature_request.yml) |
| Security vulnerability | [`SECURITY.md`](SECURITY.md) — **not** a public issue |
| Contribute code | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

Please prefer Discussions for open-ended talk so Issues stay an actionable queue.

## Response expectations

This is a small, maintainer-run project. We aim to acknowledge reports when we can; incomplete bugs may be labeled `needs-info` and closed if there is no follow-up.

Scope is guided by [`PRODUCT.md`](PRODUCT.md). Requests that fight the beachhead or listed anti-jobs may be declined as `out-of-scope` / `wontfix`.
